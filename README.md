# 바인허브 「건강 영수증」

서울대 축제 부스용 바이럴 설문 페이지.
11문항 50초 → 체질 · 건강 점수 · 전국 백분위가 **영수증 한 장**으로 출력되고,
스토리/릴스에 올라갈 때 VYNEHERB가 자연스럽게 노출된다.

## 구성

```
web/index.html    페이지 전체 (단일 파일 · 빌드 없음 · 로고와 QR은 base64 인라인)
assets/           원본 로고 3종 + 인스타그램 QR
```

## 흐름

```
인트로 → 접수(문진표) → 설문 11문항 → 영수증 결과 → 공유 설정 → 저장/공유
```

- **접수** — 성명·성별 필수, 키·몸무게 선택
- **설문** — 체질 6문항(사상체질) + 지난 일주일 5문항(야식·카페인·수면·운동·물)
- **결과** — 체질 4종, 건강 점수 /100, 전국 백분위, 게이지, 대한민국 체질 분포
- **공유** — 1080×1920 PNG 저장 / Web Share API 공유 / 결과 링크 복사

## 프라이버시

키·몸무게는 **공유 이미지와 링크에서 기본 비공개**다.
가려진다는 사실을 접수 화면, 영수증 배지, 공유 설정 요약 세 군데에서 알린다.
URL 해시도 현재 공유 설정만 반영하므로 주소를 그대로 복사해도 값이 새지 않는다.

어떤 데이터도 서버로 전송되지 않는다. 전부 브라우저 안에서 계산한다.

## 현장 문구 수정

`web/index.html` 상단 `CFG` 블록만 고치면 된다.

```js
const CFG = {
  venue: "관악캠퍼스점",
  pos:   "POS 03",
  ig:    "@vyneherb_kr",
  tags:  "#건강영수증 #체질테스트 #바인허브"
};
```

문항·체질 설명·학점 코멘트는 바로 아래 `QA` / `QB` / `TYPES` / `GRADES` 배열에 있다.

## 로컬 확인

```bash
python -m http.server 8791 --directory web
```

## 배포

`main`에 push하면 GitHub Actions가 `web/`을 GitHub Pages로 올린다.

## 주의

결과는 **재미용**이다. 의학적 진단이 아니라는 고지가 인트로와 결과지에 들어가 있다.
BMI는 표시만 하고 건강 점수에는 반영하지 않는다.
